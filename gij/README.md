# 고일준(gij) — 라푼젤 SF 재해석 애니메이션 기획 포트폴리오

- 결과물: `고일준_포트폴리오.pptx` (16:9, 11장)
- 검수 이미지: `검수/`
- 원본 사본: `source/애니메이션/` (Google Drive 「서울IT아카데미 2/고일준」 폴더에서 복사, 원본 미수정)
  - 작품개요 PDF, R 캐릭터 시트 / 표정 시트, 루카스 캐릭터 시트 2종과 얼굴 디테일 보정 이미지, 이미지보드(큐브), 애니메이션 테스트 키프레임 2종, 테스트 영상 2개(머리카락 모션 / 루카스 턴어라운드)
- 가공본: `work/img/` (`work/prep.sh`로 생성, 큐브 글로우 · 영상 포스터는 `work/make_assets.py`)
- 빌드: `cd build && npm install && node build.js` (`PPTX_SKILL`이 없으면 테마 색 지정 단계만 건너뜀)

## 구성 (작품 1개라 목차 / 챕터 간지 없음)
- 표지 / 역량 요약 / 작품 개요 / 원작 계승과 반전(원작 요소 대응표 + 주제 '닿음') / 네 칸 줄거리
- 캐릭터 R / 루카스와 멜루진 박사 / 비주얼 스타일 바이블 / 모션 테스트 / 레퍼런스 리서치 / 엔딩

## 디자인 (이 학생 작품 기준)
- 모티프: 작가가 레퍼런스로 든 유럽 그래픽 노블(BD, 리뉴 클레르). 잉크 테두리 패널과 흰 거터, 내레이션 캡션 박스 라벨, 데이터 케이블 구분선(R의 케이블 머리카락), 네 칸 만화 줄거리, 황금 큐브와 FIN 엔딩
- 색: 양피지 크림(#EFE6D6) / 잉크(#1F1B16) / 새벽 청록(#0E2225) / 큐브 황금(#C9952F), 작품개요의 청록과 황금 보색 대비와 캐릭터 시트 팔레트에서 가져옴
- 서체: 맑은 고딕, 라틴 제목은 Palatino Linotype

## 남은 작업 / 확인 필요
- 작품 제목이 없어 Drive 폴더명(Rapunzel BD Bible)을 따라 'RAPUNZEL / 라푼젤 SF 재해석 애니메이션 기획 (가제)'로 표기. 작가가 정한 제목이 있으면 교체
- 학생이 취업으로 과정을 마치지 않아 시나리오 · 스틸컷 · 최종 영상이 없음. 기획(개요 · 세계관 · 캐릭터 · 스타일 바이블 · 모션 테스트) 중심으로 구성
- 고일준 폴더 최상위의 「시나리오」 문서는 다른 작품(현대판 알라딘, S#1 샘플) 예시 문서로 보여 제외
- AI 캐릭터 제작 / AI 숏폼 광고 / 최종 편집 / 배경 시트 폴더는 비어 있음
- 테스트 영상 2개는 Drive 링크로 연결(포스터 클릭)
- 엔딩 연락처는 작가가 직접 기입
