# 조성기(jsk, 필명 CHOSK) — 3개 작품 포트폴리오

- 결과물: `조성기_포트폴리오.pptx` (16:9, 22장)
- 검수 이미지: `검수/`
- 원본 사본: `source/` (Google Drive 「서울IT아카데미 2/조성기」 폴더에서 복사, 원본 미수정)
  - `애니메이션/` 스틸컷 · 캐릭터 시트, `워크플로우/` 제작 화면 캡처, `캐릭터/` 캐릭터 IP, `숏폼광고/` 광고 스틸 · 캐릭터 시트
- 가공본: `work/img/` (`work/prep.sh`로 생성), 카드 앞면/뒷면 합성 `work/make_cards.py`, `work/make_cardback.py`
- 빌드: `cd build && NODE_PATH=<pptxgenjs node_modules> PPTX_SKILL=<pptx skill 경로> node build.js`

## 구성
- 표지 / 목차 / 역량 요약
- A♥ 「I'm Not Joker」 EINSX 「No Smile」 스토리텔링 뮤직비디오 (9장: 간지, 개요, 캐릭터, 3막 구조, 조커 모티프, 무대 연출, AI 워크플로우 2장, 1차 편집본 영상)
- 2♦ 캐릭터 IP (5장: 간지, 캐릭터 시트, 스크롤 웹툰 「돈깨비 방망이」, 「오해소지」 프로필/이모티콘, 일상툰 「햄이 되고싶어」)
- 3♠ AI 숏폼 광고 세로형 스토리보드 (4장: 간지, 캐릭터, S#1, S#2~S#3)
- 엔딩

## 디자인 (이 학생 작품 기준)
- 모티프: 「I'm Not Joker」의 트럼프 카드 / WILD CARD. 챕터를 카드 랭크로 표기(A♥ / 2♦ / 3♠)
- 챕터 간지: 흐린 대표 장면 위에 카드 뒷면 두 장과 대표 이미지가 든 카드 앞면을 흩뿌린 테이블 연출, 오른쪽에 대형 랭크와 무늬
- 색: 누아르 블랙 바탕, 조커 립 레드(#B3122E), 카드 아이보리(#F3EBDD). 챕터 무늬색 ♥ 레드 / ♦ 앰버 / ♠ 네이비
- 서체: 영문 디스플레이 Impact, 본문 맑은 고딕
- 흐린 배경: 대극장 무대 / 골목 / 웹툰 페이지(밝게) / 광고 골목(남색)

## 남은 작업
- 뮤직비디오는 「1차 편집(아임낫조커)미완.mp4」(386MB)만 있어 링크로 연결하고 '1차 편집 / 미완성'으로 표기. 완성본이 나오면 링크 교체
- 숏폼 광고: 기획서 · 시나리오 · 영상이 없어 스틸컷에서 보이는 연출만 서술. 광고 대상(제품/서비스)과 영상은 작가 확인 후 추가
- 「작품링크」 문서가 비어 있음
- 엔딩 연락처는 작가가 직접 기입
