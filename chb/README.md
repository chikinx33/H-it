## 디자인 (이 학생 작품 기준)
- 모티프: 오피스 문구. 챕터 간지는 사원증(목걸이 줄 + 사진 + 사원번호 CH-0N + 바코드), 라벨은 형광펜, 자료 사진은 테이프, 목차와 엔딩은 포스트잇
- 색: 차콜 / 종이 / 형광펜 옐로(#FFE14D) / 사원증 줄 블루(#2B59C3, 10MOO 목걸이와 같은 파랑) / 칸쵸 오렌지
- 사원증 사진: 1장 나신입, 2장 10MOO 후드형, 3장 콘티 속 주인공, 표지는 10MOO 기본형
- 서체: 맑은 고딕
