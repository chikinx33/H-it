- 가공본: `work/img/` (흐린 배경 사본, 챕터 이미지, 원형 인물 크롭, 스토리보드 패널 발췌, 꼬리 곡선 PNG), `work/make_tail.py`

## 디자인 (이 학생 작품 기준)
- 모티프: 작품 제목 「연결 꼬리」에서 가져온 불씨 꼬리 곡선. 표지에서 세 작품의 원형 이미지를 잇고, 목차의 세 챕터를 세로로 잇고, 챕터 간지에서 번호와 제목을 가른다
- 색: 코코아 브라운 바탕, 화로 앰버/엠버 강조. 챕터별 색 띠는 01 엠버(#E8552B) / 02 문어 코랄(#EE6F7C) / 03 스크래처 크라프트(#B8895A)
- 서체: 본문 맑은 고딕, 번호/영문은 Georgia 이탤릭
- 챕터 간지: 좌측 작품 색 띠 + 대형 이탤릭 번호 + 흰 꼬리 선, 우측은 작품 대표 이미지 (불꽃 고리 토리 / 말랑과 말라칸 / 고양이와 제품 풀샷)
- 흐린 배경: 01 따뜻한 부엌 장면(어둡게), S#2 심야 부엌(남색), 02 웹툰 콘티(밝게), 03 제품 거실(밝게)

## 남은 작업
- 「너와 나의 연결 꼬리」 티저 완성본: Drive 「최종 편집」 폴더가 비어 있어 '제작 진행 중'으로 표기. 토리 모션 테스트 영상(토리 해피홀스4.mp4)만 링크
- 「나는 문어, 말랑」 이모티콘 / 굿즈 / 로고 / 홍보영상 폴더가 비어 있어 이모티콘은 기획 문서 내용만 수록
- 벅뻑 광고 영상(133MB)은 다운로드 불가. 대표 이미지 클릭 시 Drive 재생. 대표 이미지는 스토리보드 제품 풀샷 패널 사용
- 마녀오두막 평면도(9.6MB)는 커넥터 한도로 제외
- 엔딩 연락처는 작가가 직접 기입
