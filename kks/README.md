## 구성
- 표지 / 목차(앨범 한 면) / 역량 요약
- No.01 「블랙홀에 기대다」 (10장: 간지, 작품 개요, 경수 연령 시트, 갠지와 가족, 4막 15씬 구성, 일기와 앨범의 복선, 상실의 감정선, 생활 유머, 수미상관과 엔딩 문구, 1차 편집본 영상)
- No.02 화투 캐릭터 IP 「光」 (6장: 간지, 라인업, 대표 캐릭터 1월 학, 캐릭터 시트 7종, 일상툰 1화, 이모티콘과 굿즈)
- No.03 「어른폰 십팔 Pro」 숏폼 광고 콘티 (3장: 간지, 스토리보드 전체, 언어유희 반전 구조)
- 엔딩

## 디자인 (이 학생 작품 기준)
- 모티프: 앨범과 블랙홀. 콘텐츠 면은 앨범(흰 인화 테두리 + 크라프트 포토 코너 + 필름 카메라 날짜 각인 스타일의 씬/컷 번호), 챕터 간지와 표지 · 엔딩은 갠지의 발광 링을 블랙홀 테두리로 삼아 원형 장면을 담음
- 색: 보이드 블랙(#0F0E13) / 앨범 크림(#F2EADC) / 크라프트 브라운(#4A3A2E) / 갠지 링 시안(#46D3E6) / 필름 날짜 오렌지(#F28C28) / LED 앰버(엔딩 전광판 문구)
- 서체: 맑은 고딕, 각인 숫자는 Courier New
- 라벨과 글머리표는 사각형 대신 갠지 눈의 링 모양

## 남은 작업 / 확인 필요
- 제목: 작품개요는 「혼자만의 추억」, 시나리오와 엔딩 타이틀은 「블랙홀에 기대다」. 덱은 시나리오 제목을 쓰고 개요 슬라이드에 '기획 단계 가제'로 표기
- 애니메이션 영상: 최종 편집 폴더의 「씬01 1차 편집본」(45MB) · 「씬02 1차 편집본」(7MB)을 링크. 완성본이 나오면 교체
- 스틸은 S#01~S#11까지만 있어 결말(S#13~15)은 시나리오 속 LED 전광판 문구를 도형으로 표현
- 캐릭터 IP: 설정 문서가 없어 IP 이름은 로고 「光」으로 표기, 캐릭터 성격은 각 시트의 기본 정보에서 발췌. 홍보영상 폴더는 비어 있음
- 화투 모티프는 월별 동물 구성과 光 로고에서 읽은 해석. 작가 확인 권장
- 숏폼 광고: 스토리보드 상단 'Shapes and Friends'는 양식 기본값으로 보여 제목으로 쓰지 않고, 엔딩 카피의 제품명 「어른폰 십팔 Pro」를 작품명으로 사용. 작가가 정한 제목이 있으면 교체
- 광고 콘티에 실제 매장 간판 · 애플 스토어 사진 · 실존 코미디언 얼굴 밈(정류장 광고판 컷)이 참고 이미지로 들어 있음. 공개용이면 초상권 / 상표 확인 필요(반전 구조 슬라이드에는 해당 컷 미사용)
- 엔딩 연락처는 작가가 직접 기입

## 집에서 수정 / 빌드하기
- 준비: Git, Node.js 18 이상, Python 3(검사용), Claude Code. 이미지를 새로 가공할 때만 ImageMagick과 bash(Windows는 WSL 또는 Git Bash)
- 빌드
  ```bash
  cd kks/build
  npm install
  node build.js
  cd ../..
  pip install python-pptx pillow
  python3 tools/check_deck.py kks/김경수_포트폴리오.pptx
  ```
- `PPTX_SKILL` 환경변수가 없으면 PowerPoint 테마 색 지정 단계만 건너뜀(슬라이드 모양은 동일)
- 문구 · 배치 수정은 `build/build.js`에서. PPTX를 PowerPoint에서 직접 고친 뒤 다시 빌드하면 직접 고친 내용이 덮어써짐
- 사진 교체 시: `source/`에 원본을 넣고 `work/prep.sh` 실행 후 다시 빌드(`work/dims.json`도 함께 갱신됨)
- 저장소 루트의 `CLAUDE.md`에 문구 방침과 덱 제작 규칙(빈 텍스트 창 금지, 이미지 비율 유지 등)이 있음
