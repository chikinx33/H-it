## 디자인 (이 학생 작품 기준)
- 작품의 색 설계(차갑고 탁한 청회색에서 노을빛으로)를 덱 진행에 그대로 적용: COLD(청회색) → HARD(S#4, 가장 어두운 톤) → TRANS(S#5 전환) → WARM(S#6 노을) → IP(스피키 & 포니 크림 톤)
- 모티프: 편집 타임코드(Consolas) 라벨, 장면별 평균 색(스틸컷 실측) 스와치, 127초 비례 타임라인
- 표지: 출근길(S#1)과 퇴근길(S#6) 좌우 대비 + 작가의 캘리그라피 제목 이미지
